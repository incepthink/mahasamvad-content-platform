# Storyboards and Videos (Conversations)

The two beta menu entries **"स्टोरीबोर्ड (beta)"** and **"व्हिडिओ (beta)"** open one conversation workspace in two modes. You work by writing instructions and following up, much like a chat.

## Choose the mode

At the top of a new conversation, **"संभाषणाचा प्रकार"** offers:

- **"स्टोरीबोर्ड"** — write a script and storyboard, revise scenes, and create pictures of scenes when you ask for them. No video is rendered.
- **"व्हिडिओ"** — create a short video clip from your prompt, then edit it with follow-up instructions.

The mode is fixed by the first message (**"या संभाषणाचा प्रकार पहिल्या संदेशासोबत ठरला आहे"**). Use **"नवीन संभाषण"** to switch. The list on the left shows **"तुमची संभाषणे"** and **"इतर संभाषणे"**, each marked with its mode.

## Storyboard mode

Write a request such as “या टिपणीवरून ६० सेकंदांच्या व्हिडिओचा स्टोरीबोर्ड तयार करा” (paste the note in the same message) and select **"पाठवा"**. The answer is written scene by scene. Follow up with changes such as “दृश्य २ लहान करा” or “दृश्य ३ नंतर एक दृश्य जोडा”; each answer is a complete revised storyboard.

Ask explicitly for pictures (“पहिल्या दृश्याचे चित्र तयार करा”) and up to four are created under **"तयार केलेली चित्रे"**. Attach your own pictures with **"संदर्भ-चित्र जोडा"** to have them used.

Facts come only from what you supply; missing details are left as placeholders. Questions outside scripts and storyboards are politely declined.

## Video mode

1. Write the prompt, choose **"व्हिडिओचा आकार"** — **"आडवा १६:९"** or **"उभा ९:१६"** — and optionally attach up to four pictures with **"संदर्भ-चित्र जोडा"**.
2. Select **"व्हिडिओ तयार करा"**. A clip takes a few minutes; only one can be generated at a time in a conversation.
3. To change it, write the change and select **"बदल करा"** — for example “पार्श्वभूमी बदला” or “हेच दृश्य, पण संध्याकाळी”.

### How an attached picture is used

Under **"चित्राचा वापर"** choose:

- **"प्रॉम्प्टनुसार"** (default) — the AI decides from your words.
- **"चित्र सजीव करा"** — the picture becomes the first frame and is animated. Use exactly one picture; this always makes a new clip.
- **"संदर्भ म्हणून वापरा"** — keep the person, object or style from the picture in a new scene.

If a clip did not use your picture, select **"मूळ चित्रावरून पुन्हा तयार करा"** on that video to start again from the original picture instead of editing the drifted clip.

### Characters and voices

Open **"पात्रे व आवाज"** to save characters — **"नाव"**, **"दिसणे"**, **"आवाज"** and an optional **"संदर्भ-छायाचित्र"** (a clear waist-up photo works best) — and pick them for a conversation with **"या संभाषणासाठी निवडा"**. Their description and voice are sent with every instruction, so the same person looks and sounds the same throughout. Write the voice carefully at the start: it cannot be changed by a later instruction. A conversation's characters are fixed after its first message; saved characters can be reused in any new conversation.

### Go back to an earlier video

After many edits, characters and scenes can drift. Select **"इथून पुढे बदल करा"** on the last video that was right; your next instruction then continues from that one (**"जुन्या व्हिडिओवरून बदल"**). **"रद्द करा"** cancels this.

{% hint style="warning" %}
Video generation is a paid step on every send. Watch each clip with sound before using it. Marathi lettering inside a generated video is unreliable — avoid asking for on-screen text.
{% endhint %}
